# IDC — الهوية الرقمية (النسخة الحقيقية)

الديمو القديم (idc-demo-v8.html) زي ما هو ومتغيّرش. ده مشروع جديد جنبه بنفس الشكل والأقسام، لكن بباك اند حقيقي.

## هيكل الملفات

| الملف | الدور |
|---|---|
| `schema.sql` | **الباك اند السحابي**: جداول Supabase، الحماية (RLS)، الخزنة المشفرة |
| `schema_mysql.sql` | **الباك اند المحلي**: جداول MySQL لبيئة XAMPP / Apache |
| `api/` | نقاط اتصال PHP للتشغيل المحلي عبر XAMPP Apache |
| `js/auth.js` | تسجيل الدخول، إنشاء حساب، إدارة الجلسات |
| `js/app.js` | شاشات التطبيق، بيانات الهوية المصرية، وإدارة الوثائق |
| `js/lock.js` | قفل التطبيق (بصمة / Face ID / PIN) وتشفير نسخة الأوفلاين |
| `js/vault.js` | القسم الخاص: قفل إضافي + رمز أمان + إغلاق تلقائي |
| `js/api.js` | محرك التخزين الهجين (يعمل تلقائياً على GitHub Pages وXAMPP) |
| `js/i18n.js` | دعم اللغتين العربية والإنجليزية بالكامل |
| `index.html` + `css/app.css` | الواجهة المتجاوبة الرئيسية بنظام ألوان Material 3 الداكن |
| `u.html` | الصفحة العامة التفاعلية لكارت NFC والرمز الاستجابي QR |
| `sw.js` + `manifest.webmanifest` | تثبيت التطبيق كـ PWA والعمل بدون اتصال بالإنترنت |

## ازاي تشغّلي المشروع

### 1) الرابط المباشر (GitHub Pages)
التطبيق منشور ويعمل مباشرة على الرابط التالي:
🔗 **https://markramy1.github.io/IDC/**

### 2) التشغيل المحلي (Local Server)
من مجلد المشروع مباشرة:
```bash
npx serve . -l 3000
```
أو عبر إضافة **Live Server** في VS Code / Antigravity IDE.

### 3) التشغيل عبر XAMPP (Apache & MySQL)
1. ضعي المجلد في `C:\xampp\htdocs\IDC`.
2. استوردي `schema_mysql.sql` في phpMyAdmin.
3. افتحي `http://localhost/IDC/` في المتصفح.

### 4) الربط السحابي مع Supabase (اختياري)
- استوردي `schema.sql` في SQL Editor بمشروع Supabase.
- ضعي المفاتيح في `js/config.js` عند الرغبة.

## كارت NFC (NTAG213)
- من داخل التطبيق: توجهي إلى "الإعدادات" ثم "رابط الكارت".
- انسخي الرابط واكتبيه كـ URL Record على الكارت الذكي عبر تطبيق NFC Tools.
- الرابط يفتح صفحة `u.html` العامة للتحقق السريع.

## إزاي الحماية شغالة (ومستوياتها)
- **كلمة مرور الحساب** (Supabase Auth) للأونلاين.
- **كلمة مرور فتح التطبيق / البصمة** على الجهاز: بتفتح التطبيق وبتفك تشفير نسخة الأوفلاين (AES-GCM، المفتاح مغلّف بكلمة المرور PBKDF2 وبمفتاح الجهاز).
- **القسم الخاص والسري**: الباسورد الإضافي متخزن في السيرفر كـ bcrypt، وبعده رمز SMS، والـ RLS في قاعدة البيانات بترفض أي قراءة للخاص والسري لو الخزنة مش مفتوحة (حتى لو حد عدّل في الفرونت اند). بتتقفل بعد دقيقتين، وبعد 3 محاولات غلط بتتحظر دقيقة، وكل محاولة بتتسجل.
- **الأوفلاين**: بيانات عامة فقط. الخاص والسري مش بيتخزنوا على الجهاز أصلًا.
- **السري بتاريخ**: بعد التاريخ بيتحول لعام تلقائيًا في السيرفر نفسه.

## حدود لازم تعرفيها
- البصمة هنا عن طريق WebAuthn: نظام الموبايل هو اللي بيتحقق منك، لكن المتصفح بيحمي فتح التطبيق مش أكتر. للحماية الأعلى مستقبلًا: لفّي المشروع كتطبيق Capacitor.
- رمز الجلسة (Supabase) محفوظ في المتصفح عشان تفضلي مسجلة دخول، وقفل التطبيق بيمنع أي حد من استخدامه على جهازك.
- لو الجهاز اتفقد: سجّلي خروج من أي جهاز تاني وغيّري كلمة مرور الحساب.
- الرقم القومي والبيانات الحساسة محتاجة مراجعة قانونية قبل الإطلاق للجمهور (خصوصًا في التعامل مع جهات حكومية).
